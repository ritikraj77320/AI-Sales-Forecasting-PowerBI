# AI Sales Forecasting & Power BI Dashboard

An end-to-end sales forecasting project using Python, Machine Learning, and Microsoft Power BI.

## Project Overview

This project analyzes historical sales data, performs data cleaning and exploratory analysis, engineers features, trains machine learning models, generates future sales forecasts, and presents the results through an interactive Power BI dashboard.

## Project Pipeline

Historical Sales Data
        ↓
Data Cleaning
        ↓
Exploratory Data Analysis
        ↓
Feature Engineering
        ↓
Model Training
        ↓
Model Evaluation
        ↓
Sales Forecasting
        ↓
Future Forecast
        ↓
Power BI Dashboard
